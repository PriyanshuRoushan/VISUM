
<h1>Visum 😴🚗</h1>
<h1>Visum is a real-time Driver Drowsiness Detection System designed to help prevent road accidents by monitoring the driver’s eye and facial behavior using computer vision.</h1>

<h2>🔍 Features</h2>

Real-time detection of drowsiness using webcam

Eye and head movement tracking

Automatic alert system to wake the driver (e.g., sound alert)

Lightweight and easy to deploy on laptops or embedded devices
